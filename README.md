# AJlang

A small Hinglish scripting language with its interpreter written in x86 MASM assembly (Irvine32) for the FAST-NUCES COAL course.

```
set name Ahmed
set age 19
likho Salam :name, umar :age
agar age > 18
    likho big boy
warna
    likho kid
/
```

Status: in development. Full usage and language reference will be added on the final day.
